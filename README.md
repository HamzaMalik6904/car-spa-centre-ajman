# Car Spa Centre — independent design concept

Temporary static website concept prepared by PaceSync Systems for Car Spa Centre in Al Jurf, Ajman. It is **not the official business website**, and has not been commissioned, approved or endorsed by the business.

## Preview features

Responsive multi-page design, service finder, filterable gallery, image lightbox, location map and social links. Enquiry and preferred-visit forms prepare a browser-only WhatsApp draft; they do not store submissions, send messages or reserve appointments.

Public business information was reviewed on 29 October 2026. No current price list or real appointment inventory is claimed. Logo and social imagery remain the property of their respective owners. Image source links are recorded in `assets/sources.json`.

This repository contains only the static preview. Open `index.html` through a static web server or GitHub Pages. The preview is intended to be unpublished seven days after deployment, with local source retained for Hamza. No analytics or tracking pixels are included.
